# Obesity Level Prediction using Machine Learning

This repository contains our **Data Warehousing and Data Mining** course group project. The aim of this project is to predict an individual's obesity level based on their eating habits, physical activity, and lifestyle using machine learning and data mining techniques.

We worked with a real-world dataset by cleaning and preprocessing the data, exploring relationships between different features, training and comparing multiple machine learning models, and evaluating their performance. Along with classification, we also explored techniques such as clustering, regression, association rule mining, and outlier detection to better understand the factors that contribute to obesity.

This project was completed as part of our undergraduate coursework and is intended for learning and academic purposes.
